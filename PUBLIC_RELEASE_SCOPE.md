# Public Release Scope

Excluded from this portfolio repository:

- Original experimental dataset and raw camera recordings
- Trained model checkpoints and TensorRT engines
- Machine/server-specific configuration and filesystem paths
- PLC addresses or environment-specific network settings
- Internal logs and debug traces
- Full private research repository and its git history

The purpose of this release is to demonstrate system architecture, engineering scope and verified results without exposing research assets that may be restricted or unnecessarily sensitive.
